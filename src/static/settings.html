Settings

Password

If you forget the password, stop the server and run venv/bin/python src/main.py --remove-password.

Network

Where the server listens. 0.0.0.0 means all IPv4 interfaces, :: all interfaces, 127.0.0.1 only this computer. Changes take effect when the server restarts.

After changing the web interface address or port, open the page at the new address once the server has restarted. If you can no longer reach it, start the server with the OCPP_HTTP_HOST and OCPP_HTTP_PORT environment variables, which override these settings.

Fiscal year

The day a year starts in the energy charts' Months and Years views.

Backup

Downloads a copy of the whole database: chargers, tags and groups, charge sessions, energy history, prices and settings. It is safe to make while chargers are connected. The file also holds the password hash, so keep it somewhere private.

To restore a backup, stop the server, replace the database file (simple-ocpp.db in the data directory) with the backup, and start the server again.

Initial energy

If you know a charger's total energy reading from before it was connected here (on its display or in its app), enter it with the date you read it. The energy used between that date and the first reading this server receives is then included in the charts and totals. For chargers with more than one connector, it applies to the lowest-numbered connector.
